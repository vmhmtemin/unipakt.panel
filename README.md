# UniPakt Panel

The management panel for UniPakt member club presidents.

## 🔐 Access

The panel is accessible only to authorized club presidents approved by UniPakt.

> This repository contains the source code of the UniPakt Panel. Do not share sensitive information or credentials in the repository.

## 🖥️ Panel

Club presidents can use the panel to manage and track:

* Events
* Announcements
* Club Information
* Members
* Applications
* UniPakt.Vanguard
* Tasks

## 🌐 Domains

Production Panel:

**panel.unipakt.com**

Main Website:

**unipakt.com**

## 🛠️ Technology

* Frontend: HTML / CSS / JavaScript
* Hosting: GitHub Pages
* Authentication: Supabase Auth
* Database: Supabase
* Authorization: Supabase Row Level Security (RLS)

## ⚠️ Security

Authentication credentials must never be hardcoded into the frontend.

Supabase secret and service-role keys must never be exposed in client-side code or committed to the repository.

Panel access is protected through authentication and database-level authorization.
